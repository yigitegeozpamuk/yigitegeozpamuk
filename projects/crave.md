# CRAVE

**Short-form food discovery platform · In development**

CRAVE explores a video-first approach to discovering food and culinary experiences through an immersive mobile web interface.

## Product scope

- Short-form food video feed
- Personalized discovery concepts
- Saved content and account experiences

## Technical direction

Web development, Supabase and mobile-first interface design. The project explores video discovery and user experience.

## Status

In development. Product concepts may not all be implemented. Source code remains private.
